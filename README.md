# MatrixDevTesis
Es una suite web all-in-one construida en Python y Streamlit que simplifica la documentación técnica, el diagramado UML y la gestión de proyectos informáticos para estudiantes universitarios y desarrolladores.
Contiene:

-Ingeniería de Requisitos & Documentación:
-Acta de Constitución de proyecto.
-Definición de Alcance / MVP (Producto Mínimo Viable).
-Documentos ERS (Especificación de Requerimientos de Software).
-Historias de Usuario (User Stories).
-Requisitos Funcionales y No Funcionales.
-Diagramado & Modelado Visual:
-Diagramas de Flujo.
-Diagramas UML (Casos de Uso, Clases).
-Estructura de Desglose del Trabajo (EDT / WBS).
-Gestión de Proyectos Estilo Jira:
-Tablero de tareas dinámico estilo Kanban (Pendiente, En Proceso, Completado).
-Matriz RACI (Responsible, Accountable, Consulted, Informed).
-Matriz y Gestión de Riesgos.
-Analítica & Planificación:
-Gráficos de Barra interactivos para seguimiento.
-Indicadores Clave de Rendimiento (KPIs) del proyecto.
-Ruta Crítica calculada sobre Diagramas de Gantt.
